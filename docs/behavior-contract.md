## Deliberate implementation choices and unknowns

Use explicit ordered Rust state and tick inputs. Deterministic tests control the PRNG; this does not establish equivalent retail RNG state. Recovered source also consumes global RNG during backdrop shake. Separating rendering from simulation RNG is an explicit design decision; exact original replay parity remains unproved.

The controlled Rust first-loop execution passed in run03; retail parity remains unverified. Tests must link to the IDs above or a separately stated correctness contract. Independently measure movement, animation cadence, collision geometry, timer adjustments, and Steam compatibility; do not fill missing values with unlabelled guesses. Failed experiments and affected evidence changes go in [STATUS](../STATUS.md) and [MODLOG](../MODLOG.md).
